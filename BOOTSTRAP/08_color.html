Bootstrap 色彩與背景範例

文字背景色樣式展示

這裡示範 Bootstrap 的 .text-bg-* 類別，會自動搭配合適的文字顏色。

兩者的差別

.bg-* 主要用來設定背景顏色，但如果要搭配文字，通常還需要另外指定 .text-* 類別，才能讓文字有適合的對比顏色。

.text-bg-* 則是 Bootstrap 提供的整合寫法，除了設定背景色之外，也會自動幫文字選擇適合的顏色，使用上更方便，也更適合直接套用在 alert、badge 或其他內容區塊。
